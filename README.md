# 💼 Web HireU

> Modern Job & Career Platform built with Laravel.

Web HireU is a modern web platform designed to connect job seekers with employers and make finding, publishing, and managing job opportunities easier.

## 🚀 Project Status

Currently under development.

## 🛠️ Technologies

- PHP
- Laravel
- Blade
- Tailwind CSS
- JavaScript
- MySQL
- Stripe

## 🎯 Planned Features

- User authentication
- Job seeker accounts
- Employer accounts
- Job listings
- Company profiles
- Job applications
- CV management
- Advanced search and filtering
- Employer dashboard
- Job seeker dashboard
- Admin dashboard
- Notifications
- Featured jobs
- Arabic & English support
- Security improvements

## 📌 About

Web HireU is being developed as a full-featured job and career platform.
